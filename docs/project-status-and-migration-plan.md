# Project Status, Antigravity Hand-over and Next Steps

**Project:** Retail Supply & Demand Monitoring (Inner Jakarta)
**Date:** 13 October 2026
**Purpose:** Record what was built on Antigravity, what was left unfinished there, how the build compares to the requirements, and the ordered steps from here on Claude.

Sources used: `docs/retail-supply-demand-monitoring-requirements.md` (v0.4), `docs/frontend-design-spec.md`, the Antigravity project rules (`GEMINI.md`, `.agents/rules/`), the Antigravity planning artifacts and conversation history for the three sessions of 12–13 Oct 2026, the code in `scripts/` and `website/`, the raw files in `raw/`, and a live check of the app in the browser today.

---

## 1. Summary

- The requirements document describes a cloud-hosted app on OneDrive. On Antigravity the owner redirected Phase 1 to a **local-first, Sell-In pipeline** scope. That decision lives only in the agent rules, not in the requirements document.
- The app runs offline from `website/index.html` and has **seven views**. Three are built on **real data** (DSE Visits, Territory Management, Jakarta Inner Map). Three still run on **synthetic numbers** (Morning Sales Brief, Leaders Territory Analysis, Supply vs Demand). One is a static inventory page with stale text.
- Of the four Sell-In stages, only **Stage 2 (DSE visits)** is built. Stages 1, 3 and 4 have been assessed on paper but have no view and no feed.
- **Two requests from the last Antigravity sessions were never completed**: the Site/Outlet inactivity sub-views, and filter-driven grouping in Territory Management. One cosmetic inconsistency remains from the 4,249-site change.
- Migration housekeeping done today: `CLAUDE.md` created from the Antigravity rules, four assessment documents copied into `docs/assessments/`, a real render test added at `scripts/render_check.js`, and a preview config at `.claude/launch.json`.

## 2. Requirements vs what exists

### 2.1 Scope decisions that changed after v0.4

| Topic | Requirements v0.4 says | What was actually decided (Antigravity, 12 Oct) |
|---|---|---|
| Data location | OneDrive as system of record, Graph API app registration | **Local folder first** (`raw/`), OneDrive later |
| Phase 1 focus | Morning Brief, Leaders Analysis, Supply vs Demand | **Sell-In pipeline in four stages**: Distributor → DSE, DSE visits, Physical/electronic Sell-In, OSA and saldo |
